🚀 DEPLOYMENT INSTRUCTIONS
═══════════════════════════════════════════════════════════════════════════════

Step 1: Deploy Backend
  $ cd backend/spa-sam-app
  $ sam build
  $ sam deploy --guided

Step 2: Get WebSocket URL
  $ aws cloudformation describe-stacks \
      --stack-name <your-stack> \
      --query 'Stacks[0].Outputs[?OutputKey==`WebSocketURL`].OutputValue' \
      --output text
  
  Result: wss://xxxxxxxxxx.execute-api.region.amazonaws.com/Prod

Step 3: Update Frontend
  Edit: frontend/src/app/pages/messages/messages.component.ts
  Update line 76 with your WebSocket URL

Step 4: Build Frontend
  $ cd frontend
  $ npm install
  $ npm run build

Step 5: Deploy Frontend
  Upload dist/ folder to your hosting service (S3, Amplify, etc.)
